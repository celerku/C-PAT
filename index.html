Disclaimer & interpretation

This tool highlights potential issues such as excessive colour variation. Never assume downsized artwork is AI-generated. Colour counts alone cannot establish whether artwork is valid or invalid. Always consider multiple independent reasons, review the artwork in context and ask for clarification before making a decision.

Please contact @in_celerku for more information or an explanation of these results.

5. Pixel inspection & stray pixels

Stray detection flags small connected regions of identical RGBA pixels. These are suggestions, not guaranteed errors. No pixels are modified.

6. Animation controls

Frame comparisons use fully composited frames and exact RGBA differences. GIF delays are reported per frame; average FPS is total frames divided by total duration.

Uploading from SMMO?

Uploading SimpleMMO Image/GIF Files?

SimpleMMO currently has a Cloudflare problem that can cause static files displayed in-game to appear blurred, potentially introducing more colours than the original artwork contains. Downloading and uploading the altered image would analyse the altered artwork rather than the original.

1. Upload the original file

If you have the original file, upload it directly into this tool. It does not need to be upscaled.

2. Analysing a GIF (Animated Avatar)

  • You can right-click the image, select Copy Image, and paste it directly into the tool to analyse the first frame of the animation.
  • To analyse the GIF, right-click the image and select Download Image. The image will save in .png.webp format.
  • Go to a WebP to GIF Converter and convert the file to a .gif. IMPORTANT — Do not skip this step.
  • Upload the resulting .gif file into this tool.

WARNING: Do not use, edit, or share these files without explicit approval from the original artist and the art commissioner.
