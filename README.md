# Image Analyser

A browser-based tool for inspecting pixel art, analysing colour usage, exploring animations and exporting image data.
Created by **@in_celerku**.

**All image analysis is performed locally in your browser.** Uploaded images are not sent to a server by the analyser.

## Features

### Image inspection
* Upload PNG, JPEG, WebP and GIF images.
* Paste images directly from your clipboard.
* Load images from direct URLs where permitted by the image host.
* Zoom in to inspect individual pixels.
* View pixel coordinates and RGBA colour values.
* Use a hover magnifier and lock pixel selections.
* Highlight selected colours or suspicious small pixel clusters.

### Colour analysis
* View image dimensions and pixel counts.
* Analyse unique colours, transparency and colour composition.
* Display the most frequently used colours and their usage percentages.
* Generate palettes using exact colours, popular colours or an approximated palette.
* Inspect HEX, HEXA, RGB and RGBA values.
* View transparent colours against a checkerboard background.

### Animation tools
* Explore individual GIF frames using a timeline.
* Play, pause and navigate animations.
* Inspect frame delays and animation duration.
* Analyse colours across an entire animation.
* Compare two frames and highlight changed pixels.

**Note:** Animated WebP decoding depends on browser support. If an animated WebP file cannot be decoded, convert it to GIF before uploading.

### Export options
Download your analysis as:
* Palette PNG
* Colour CSV
* Analysis TXT
* Analysis JSON
* Selected frame PNG

## How to use
1. Open the Image Analyser in a desktop browser.
2. Upload an image, paste one from your clipboard or enter a direct image URL.
3. Use the controls to choose which information you want to display.
4. Inspect the preview, colour analysis, palette or animation timeline.
5. Download any results you need using the export controls.

You can collapse and rearrange the analysis panels using their headings and drag handles.

**Do not use, edit or share artwork without permission from the original artist and commissioner.**

## Disclaimer: Results
Image Analyser can flag potentially excessive colour variation and suspicious small clusters of pixels. These findings are intended to support closer inspection.

**A high colour count does not prove that an image was AI-generated, edited improperly or created against any particular art rules.**

Colour variation may result from compression, resizing, transparency, anti-aliasing, image conversion or other processing.
Always consider the artwork's context, review multiple sources of evidence and seek clarification before drawing conclusions.
